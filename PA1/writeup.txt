Test Cases:

Test 1:
  Input:
    int x = 0;
    // set x
    x = x + 1;

  Expected Output:
    <KEYWORD, int> : (1:1)
    <ID, x> : (1:5)
    <OPERATOR, => : (1:7)
    <INTEGER, 0> : (1:9)
    <PUNCTUATION, ;> : (1:10)
    <ID, x> : (3:1)
    <OPERATOR, => : (3:3)
    <ID, x> : (3:5)
    <OPERATOR, +> : (3:7)
    <INTEGER, 1> : (3:9)
    <PUNCTUATION, ;> : (3:10)

  This tests keyword, identifier, operator, and integer token recognition
  along with single line comment skipping and line tracking
